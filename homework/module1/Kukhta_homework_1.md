## Завдання 1. Дослідження мережі

### 1.1. Команда

```bash
ip a
```

### 1.2. Результат виконання команди

```text
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN group default qlen 1000
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    inet 127.0.0.1/8 scope host lo
       valid_lft forever preferred_lft forever
    inet6 ::1/128 scope host
       valid_lft forever preferred_lft forever
2: wlan0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP group default qlen 1000
    link/ether ce:31:0d:29:67:44 brd ff:ff:ff:ff:ff:ff
    inet 192.168.0.187/24 brd 192.168.0.255 scope global dynamic wlan0
       valid_lft 6521sec preferred_lft 6521sec
    inet6 fe80::18da:725d:95bd:68b5/64 scope link
       valid_lft forever preferred_lft forever
```

### 1.3. Параметри підключення

| Параметр | Значення |
|---|---|
| Інтерфейс | `wlan0` |
| Тип підключення | Wi-Fi |
| Стан інтерфейсу | `UP` |
| MAC-адреса | `ce:31:0d:29:67:44` — канальний рівень, OSI L2 |
| Локальна IPv4-адреса | `192.168.0.187` — мережевий рівень, OSI L3 |
| Маска підмережі | `255.255.255.0`, або `/24` — мережевий рівень, OSI L3 |
| Адреса мережі | `192.168.0.0` |
| Gateway | `192.168.0.1` |
| Broadcast | `192.168.0.255` |
| Діапазон host-адрес | `192.168.0.1–192.168.0.254` |
| Кількість доступних host-адрес | 254 |

Інтерфейс `wlan0` увімкнений та має стан `UP`. Позначка `dynamic` означає, що IPv4-адресу було отримано автоматично.

## Завдання 2. Дослідження маршрутизації

### 2.1. Команда

```bash
ip r
```

### 2.2. Результат виконання команди

```text
default via 192.168.0.1 dev wlan0 proto dhcp src 192.168.0.187 metric 600
192.168.0.0/24 dev wlan0 proto kernel scope link src 192.168.0.187 metric 600
```

### 2.3. Протокол отримання IP-адреси

IP-адресу та маршрут за замовчуванням отримано через протокол **DHCP**. Це видно з позначки `proto dhcp` у першому рядку результату `ip r`.

Маршрут за замовчуванням проходить через gateway `192.168.0.1` та інтерфейс `wlan0`. Другий рядок створено ядром Linux (`proto kernel`): він показує, що мережа `192.168.0.0/24` підключена безпосередньо, а локальна адреса комп’ютера — `192.168.0.187`.

## Завдання 3. Знаходження публічної IP-адреси

### 3.1. Команда

```bash
curl ifconfig.io
```

### 3.2. Результат виконання команди

```text
194.39.227.109
```

### 3.3. Порівняння локальної та публічної адрес

| Тип адреси | Значення |
|---|---|
| Локальна IP-адреса | `192.168.0.187` |
| Публічна IP-адреса | `194.39.227.109` |

Адреси **не однакові**. `192.168.0.187` є приватною IP-адресою, яка використовується лише в локальній домашній мережі та безпосередньо не маршрутизується через Інтернет.

Домашній роутер має локальну адресу `192.168.0.1` і виконує трансляцію мережевих адрес — NAT. Під час виходу пристрою в Інтернет роутер замінює його приватну адресу зовнішньою публічною адресою. Саме тому зовнішні вебсайти бачать `194.39.227.109`, а не `192.168.0.187`. Публічна адреса також може належати інтернет-провайдеру, VPN-сервісу або спільному CGNAT-шлюзу.
